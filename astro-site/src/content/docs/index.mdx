## What is heartKIT?

heartKIT brings signal preparation, model development, evaluation and export into one Python workflow for ECG and PPG applications. Start with a built-in task and configuration, then change the data or model to fit the question you are working on.

You can run a configured workflow from the command line or use the Python API to assemble one yourself. The task pages explain each application; the guides walk through examples, and the API reference covers the underlying interfaces.

## Installation

In a Python 3.12 project, add heartKIT and check that the command line tool is available:

```bash
uv init --python 3.12 my-heart-project
cd my-heart-project
uv add heartkit
uv run heartkit --help
```

The [quickstart](/heartkit/quickstart/) covers other installation methods and your first workflow.
